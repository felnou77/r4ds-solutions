11.0.5 Question 3

How do labels with geom_text() interact with faceting? How can you add a label to a single facet? How can you put a different label in each facet? (Hint: Think about the dataset that is being passed to geom_text() )

Solution:

Whenever you are working with facets and annotations: Always pass a separate data.frame to your annotation layer (like geom_text), and ensure that data.frame contains the faceting variable. This gives you total control over exactly what text appears in which box.

Below, you find a code that illustrate this mechanism

Code 
# Create a multi-row dataset with a unique label for each facet
multi_label_data <- data.frame(
  drv = c("4", "f", "r"),  # The three facets
  hwy = c(40, 40, 40),     # Y coordinates for each label
  displ = c(5, 5, 5),      # X coordinates for each label
  label = c(
    "4WD vehicles", 
    "Front-wheel drive", 
    "Rear-wheel drive"
  )
)

ggplot(mpg, aes(x = displ, y = hwy)) +
  geom_point() +
  facet_wrap(~ drv) +
  geom_text(
    data = multi_label_data, 
    aes(label = label),
    color = "blue",
    fontface = "bold"
  )

Why doesn’t the following code override the default scale?

Solution:

To override the default blue gradient inside the hexagons, you must use scale_fill_gradient() instead.

Code 
df <- tibble(
  x = rnorm(10000),
  y = rnorm(10000)
)

ggplot(df, aes(x, y)) +
  geom_hex() +
  scale_fill_gradient(low = "white", high = "red") +
  coord_fixed()

11.0.9 Question 2

What is the first argument to every scale? How does it compare to labs()?

Solution:

The first argument to every single scale_* function is name. This argument controls the text label that appears as the axis title or the legend title for that specific scale. labs & scale do the exact same thing for axis and legend titles.

Exercises 11.6.1

11.0.14 Question 1

What happens if you omit the parentheses in the following plot layout. Can you explain why this happens?

Code 
p1 <- ggplot(mpg, aes(x = displ, y = hwy)) + 
  geom_point() + 
  labs(title = "Plot 1")
p2 <- ggplot(mpg, aes(x = drv, y = hwy)) + 
  geom_boxplot() + 
  labs(title = "Plot 2")
p3 <- ggplot(mpg, aes(x = cty, y = hwy)) + 
  geom_point() + 
  labs(title = "Plot 3")

p1 | p2 / p3

Solution:

Instead of having Plot 1 and Plot 2 side-by-side on the top row with Plot 3 spanning the entire bottom row, you will get a two-column layout.

In R, apparently, the division operator (/) has a higher mathematical precedence than the logical OR operator (|). Therefore, the expression p1 | p2 / p3 is evaluated as p1 | (p2 / p3).

11.0.15 Question 2

Using the three plots from the previous exercise, recreate the following patchwork.

Solution:

Code 
library(ggplot2)
library(patchwork)

# 1. Define the three individual plots
p1 <- ggplot(mpg, aes(x = displ, y = hwy)) + 
  geom_point() + 
  labs(title = "Plot 1")

p2 <- ggplot(mpg, aes(x = drv, y = hwy)) + 
  geom_boxplot() + 
  labs(title = "Plot 2")

p3 <- ggplot(mpg, aes(x = cty, y = hwy)) + 
  geom_point() + 
  labs(title = "Plot 3")

# 2. Combine and tag the plots using patchwork
patchwork_layout <- p1 / (p2 | p3)

patchwork_layout + 
  plot_annotation(
    tag_levels = "A", 
    tag_suffix = ":",
    tag_prefix = "Fig. "
  )

### Question 1

> What happens if you omit the parentheses in the following plot layout. Can you explain why this happens?

```{r}
p1 <- ggplot(mpg, aes(x = displ, y = hwy)) + 
  geom_point() + 
  labs(title = "Plot 1")
p2 <- ggplot(mpg, aes(x = drv, y = hwy)) + 
  geom_boxplot() + 
  labs(title = "Plot 2")
p3 <- ggplot(mpg, aes(x = cty, y = hwy)) + 
  geom_point() + 
  labs(title = "Plot 3")

p1 | p2 / p3
```

**Solution:**

> Instead of having Plot 1 and Plot 2 side-by-side on the top row with Plot 3 spanning the entire bottom row, you will get a two-column layout.

>In R, apparently,  the division operator (/) has a higher mathematical precedence than the logical OR operator (|). Therefore, the expression p1 | p2 / p3 is evaluated as p1 | (p2 / p3).

### Question 2 

> Using the three plots from the previous exercise, recreate the following patchwork.

**Solution:**

```{r}
library(ggplot2)
library(patchwork)

# 1. Define the three individual plots
p1 <- ggplot(mpg, aes(x = displ, y = hwy)) + 
  geom_point() + 
  labs(title = "Plot 1")

p2 <- ggplot(mpg, aes(x = drv, y = hwy)) + 
  geom_boxplot() + 
  labs(title = "Plot 2")

p3 <- ggplot(mpg, aes(x = cty, y = hwy)) + 
  geom_point() + 
  labs(title = "Plot 3")

# 2. Combine and tag the plots using patchwork
patchwork_layout <- p1 / (p2 | p3)

patchwork_layout + 
  plot_annotation(
    tag_levels = "A", 
    tag_suffix = ":",
    tag_prefix = "Fig. "
  )
```
