1.0.3 Question 3

Make a scatterplot of bill_depth_mm VS. bill_length_mm. That is, make a scatterplot with bill_depth_mm on the y-axis and bill_length_mm on the x-axis. Describe the relationship between these two variables.

Solution:

The goal was to create a scatter plot of bill_length versus bill_depth and infer the relationship between these variables.

During this quick visualization task, and after examining the first figure (Overall, the left one), it turned out there was no relationship e.g. suggesting that the longer a penguin’s bill is, the thicker it gets…

Code 
ggplot(data = palmerpenguins::penguins,

1.0.4 Question 4

What happens if you make a scatterplot of species vs. bill_depth_mm? What might be a better choice of geom?

Solution:

From left to right, the first figure directly answers the question. We notice that the observations are grouped along a vertical line for each species. As we can also see, there is a degree of overlap between these tightly packed observations.

It is expected to obtain this type of output, as ‘species’ is a categorical variable taking on only three values in this context. One way to bypass this issue is to introduce a new geom, namely geom_jitter(), which adds a form of noise (vertical and/or horizontal) to better visualize these clusters `(as you can notice, ‘height’ is set to 0 to preserve the actual value of the numerical variable) i.e. : Only an horizontal noise was applied to the numerical variable.

This noise is applied horizontally to spread out the points and make the distribution more visible. The resulting plot will show the distribution of bill_depth_mm for each species with clearer separation between the points.

Code 
ggplot(data = palmerpenguins::penguins, 
       mapping = aes(x = species, y = bill_depth_mm))+
       geom_point()
ggplot(data = palmerpenguins::penguins, 
       mapping = aes(x = species, y = bill_depth_mm))+
       geom_jitter(height = 0, width = 0.14, alpha = 0.5)

1.0.7 Question 8

Recreate the following visualization. What aesthetic should bill_depth_mm be mapped to? And should it be mapped at the global level or at the geom level?

Solution:

Why Both Codes Produce the Exact Same Output ?

At first glance, you might expect Code 1 to draw multiple trend lines (one for each color) because color = bill_depth_mm is placed inside the global ggplot() aesthetic mapping. However, both snippets render an identical plot: a single overall smooth line over points colored by a gradient scale.

This is the key reason: bill_depth_mm is a continuous numerical variable, not a discrete categorical variable (like species).

When you map a categorical variable (e.g., color = species) globally, geom_smooth() automatically splits the dataset into distinct groups (Adelie, Chinstrap, Gentoo) and fits three separate trend lines.

When you map a continuous numerical variable (e.g., color = bill_depth_mm), ggplot2 treats the data as a single continuous distribution rather than discrete subgroups.

Code 
#code 1
ggplot(data=palmerpenguins::penguins, 
       mapping = aes(x = flipper_length_mm, y = body_mass_g, color=bill_depth_mm))+
       geom_point()+
       geom_smooth(method='loess')
#code 2
ggplot(data=palmerpenguins::penguins, 
       mapping = aes(x = flipper_length_mm, y = body_mass_g))+
       geom_point(aes(color=bill_depth_mm))+
       geom_smooth(method='loess')

What does the bins argument in geom_histogram() do?

Solution:

The bins argument in geom_histogram() sets the total number of equal-width bars used to divide and display the distribution of your data on the x-axis.

1.0.13 Question 4

Solution:

Here is a tip to find and set directly the most useful and interesting bindwidths : we start by plotting the density of our variable carat using geom_density() function and then start to inspect the range of values that takes our variable on the x-axis. As you can see the carat variable takes values starting from zero to five. Therfore, it is thoughfully proper to set the bins/binwidth argument to a value that divides this range into a reasonable number of intervals. For exmaple, setting in this example, bindwidth to 10 will generates an histogram with a single bloc and such a thing doesn’t show the distribution of our variable.

Code 
ggplot(diamonds, aes(x = carat)) +
  geom_density()
ggplot(diamonds, aes(x = carat)) +
  geom_histogram(binwidth = 0.1)

  geom_histogram(binwidth = 10)

To detect categorical variables in a dataset, you look for columns containing text labels, repeating distinct values, or discrete data that represent groups or categories.

Here variables such as class, manufacturer, year(only two values are present in the mpg dataset), class… are categorical variables. displ,cty & hwy are numerical variables. Here is a code snippet that performs an initial rough separation of these two types of variables. After that, only a human quick and minor check remains.

Code 
# Initialize an empty vector
L <- c()

# Loop through column names
for (col in colnames(mpg)) {
  if (length(unique(mpg[[col]])) <= 15) {
    L <- c(L, col)
  }
}

# Print matching columns
for (catg in L) {
  print(catg)
}

1.0.15 Question 2

Make a scatterplot of hwy vs. displ using the mpg data frame. Next, map a third, numerical variable to color, then size, then both color and size, then shape. How do these aesthetics behave differently for categorical vs. numerical variables?

Solution:

When mapping a numerical variable to these aesthetics in ggplot2, they generate continuous gradients. When mapping a categorical variable, they generate discrete sets of distinct values.

Shape: ggplot2 does not allow mapping continuous numerical variables to shape. Shape is a discrete aesthetic, limited to a small set of symbols. Attempting to map a numerical variable to shape will result in an error.

Code 
ggplot(data = mpg, aes(x = hwy, y = displ)) +
  geom_point() +
  labs(title = "Scatterplot of hwy vs. displ")
ggplot(data = mpg, aes(x = hwy, y = displ, color = cty)) +
  geom_point() +
  labs(title = "Scatterplot of hwy vs. displ")
ggplot(data = mpg, aes(x = hwy, y = displ, color = cty, size = cty)) +
  geom_point() +
  labs(title = "Scatterplot of hwy vs. displ")

1.0.16 Question 3

In the scatterplot of hwy vs. displ, what happens if you map a third variable to linewidth?

Solution:

In a standard scatterplot created with geom_point(), nothing visible will happen if you map a variable to the linewidth aesthetic.

The linewidth aesthetic is designed to control the thickness of lines, such as those generated by geom_line() or geom_smooth().

1.0.17 Question 5

Make a scatterplot of bill_depth_mm vs. bill_length_mm and color the points by species. What does adding coloring by species reveal about the relationship between these two variables? What about faceting by species?

Solution:

Upon inspecting the graph, we notice that (within each species) as the penguins’ bill depth increases, their bill length also gains in length. This is something we might have missed revealing had we not introduced the third categorical variable (species).

Adding faceting by species reveals that the relationship between bill depth and bill length is consistent across species, but with some variation in the scale of the relationship. This suggests that while there is a general positive correlation between bill depth and bill length, the magnitude of this relationship may differ slightly between species.

Another potential explanation of this positive relationship would be that penguins simply when they grow up develop gradually bigger and thicker bills (Saying so : we suppose that our data contains maybe baby penguins along with adults ones).

Code 
ggplot(data    = palmerpenguins::penguins,
       mapping = aes(x = bill_depth_mm, y = bill_length_mm, color = species)) +
       geom_point()+
       facet_wrap(~species)

Why does the following yield two separate legends? How would you fix it to combine the two legends?

First thing, let’s remove the labs function and see what it does. We seem to have a single legend (color and shape) named species with a lowercase 's' : And that’s what we slightly want. Now to explain the behaviour of the code, we notice that labs labels the legend of color palette as 'Species' without explicitly labeling the shape which was creadted by default as 'species' and that’s why we have two legends. > Here is a `tip` to find and set directly the most useful and interesting bindwidths : we start by plotting the density of our variable `carat` using `geom_density()` function and then start to inspect the range of values that takes our variable on the x-axis. As you can see the `carat` variable takes values starting from `zero` to `five`. Therfore, it is thoughfully proper to set the bins/binwidth argument to a value that divides this range into a reasonable number of intervals. For exmaple, setting in this example, bindwidth to 10 will generates an histogram with a single bloc and such a thing doesn't show the distribution of our variable.

```{r}
#| warning: false
#| layout-ncol: 3
#| fig-width: 5


ggplot(diamonds, aes(x = carat)) +
  geom_density()

ggplot(diamonds, aes(x = carat)) +
  geom_histogram(binwidth = 0.1)

ggplot(diamonds, aes(x = carat)) +
  geom_histogram(binwidth = 10)

```

>Why does the following yield two separate legends? How would you fix it to combine the two legends?
